## Simple Sales Dashboard using Tableau


## Objective
To create a clean, interactive dashboard that displays sales performance by product category, region, and month using Tableau.


##  Dataset
- File: Sample - Superstore.csv
- Columns used: Order Date, Region, Category, Sales


##  Visuals Created
1. Line Chart – Monthly Sales Trend
2. Bar Chart – Sales by Region
3. Donut Chart – Sales by Category


##  Filters
- Region filter added for user interaction
- Applied to all visuals using “Apply to all using this data source”

## Design Choices
- Donut chart built using dual-axis technique
- Highlighted top-performing region using color
- Clean layout with subtle backgrounds and borders

##  Key Insights
- The West region had the highest sales, especially in Q3.
- Technology was the top-selling category across all regions.
- Sales peaked in November and December, suggesting a seasonal pattern.
